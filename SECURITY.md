# Security Policy

## Supported versions

Security fixes are applied to the latest code on the default branch. Please update before reporting an issue against an older checkout.

## Reporting a vulnerability

Do not report suspected vulnerabilities in a public issue. Use GitHub's private vulnerability-reporting flow for this repository. If private reporting is unavailable, contact the repository owner privately through GitHub and include enough detail to reproduce the issue.

Please include the affected version or commit, deployment details relevant to the issue, reproduction steps, and the potential impact. Reports will be acknowledged as soon as possible and coordinated before disclosure.
